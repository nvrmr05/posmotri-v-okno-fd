# Посмотри в окно

GitHub: https://github.com/nvrmr05/posmotri-v-okno-fd

Веб-приложение для поиска и просмотра видео из разных городов. Пользователь может выбрать город и время суток, чтобы найти подходящие видеозаписи.

Интерфейс оформлен в соответствии с макетом проекта. Сохранена функциональность приложения: поиск, переключение видео и загрузка дополнительных карточек.

## Технологии

- HTML5 (семантическая разметка)
- CSS3: Flexbox, object-fit, псевдоклассы
- JavaScript: DOM, обработчики событий, Fetch API, async/await
- Шрифты Oswald и Fira Sans Condensed

## Структура страницы

1.Видеоплеер: большое окно для просмотра выбранного видео.
2.Форма поиска: поле для ввода города и чекбоксы для выбора времени суток.
3.Список карточек: видео с изображениями и описаниями, выбор ролика для просмотра.
4.Кнопка «Показать ещё»: загрузка дополнительных карточек.
5.Состояния загрузки и ошибки: прелоадеры во время загрузки данных и сообщение при возникновении ошибки.

## Особенности вёрстки

- Основные блоки страницы расположены с помощью Flexbox.
- Для списка карточек предусмотрена собственная прокрутка.
- Изображения в карточках настроены с помощью object-fit.
- Форма поиска позволяет выбрать город и отфильтровать видео по времени суток.
- При выборе карточки меняется видео в основном плеере.
- Во время загрузки данных отображаются прелоадеры, а при возникновении ошибки — соответствующий блок с сообщением.
